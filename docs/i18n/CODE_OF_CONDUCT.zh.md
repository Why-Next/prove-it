# 行为准则

## 简短版

做个体面的人。就代码争论，而不是就人争论。

## 详细版

本项目采用 [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 2.1 版。贡献者与维护者承诺，让每个人参与本项目的过程都不受骚扰，无论其年龄、体型、可见或不可见的残障、族裔、性征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教，还是性身份与性取向。

有助于营造积极环境的行为示例：

- 给出建设性反馈，也大方地接受它
- 承担责任，向受我们错误影响的人道歉，并从中吸取教训
- 关注什么对项目最好，而不是什么对我们自己最好

不可接受的行为示例：

- 带有性意味的言语或图像，以及任何形式的性关注或性挑逗
- 挑衅捣乱、侮辱性或贬损性的评论，以及人身或政治攻击
- 公开或私下的骚扰
- 未经他人明确许可就公布其私人信息

## 适用范围与执行

本准则适用于所有项目空间，以及个人在公共场合代表本项目的场合。

请把不可接受的行为报告到 **hello@whynext.app**。所有投诉都会被及时且公正地审阅和调查。维护者有义务尊重任何事件报告者的隐私与安全。

完整文本，包括本项目遵循的执行指引，见 https://www.contributor-covenant.org/version/2/1/code_of_conduct/
