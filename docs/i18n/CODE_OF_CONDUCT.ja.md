## 長い版

このプロジェクトは [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) バージョン 2.1 を採用する。コントリビューターとメンテナーは、年齢、体格、目に見える障害や見えない障害、民族、性的特徴、ジェンダー・アイデンティティと表現、経験の程度、学歴、社会経済的地位、国籍、容姿、人種、宗教、性的指向とアイデンティティにかかわらず、誰にとっても参加がハラスメントのない体験となるようにすることを誓う。

前向きな環境に寄与する振る舞いの例:

- 建設的なフィードバックを与え、また快く受け入れること
- 責任を引き受け、自分たちの過ちで影響を受けた人に謝り、その経験から学ぶこと
- 自分たちにとってではなく、プロジェクトにとって最善のことに集中すること

容認できない振る舞いの例:

- 性的な言葉や表現、そしてあらゆる種類の性的な関心や誘い
- 荒らし、侮辱的または軽蔑的なコメント、そして個人的または政治的な攻撃
- 公的または私的なハラスメント
- 他人の私的な情報を、明示的な許可なく公開すること

## 適用範囲と施行

これは、すべてのプロジェクト空間で、また個人が公的な場でプロジェクトを代表しているときに適用される。

容認できない振る舞いは **hello@whynext.app** に報告してほしい。すべての苦情は、速やかかつ公正にレビューされ調査される。メンテナーは、あらゆる事案の報告者のプライバシーと安全を尊重する義務を負う。

このプロジェクトが従う施行ガイドラインを含む全文は、https://www.contributor-covenant.org/version/2/1/code_of_conduct/ にある。
