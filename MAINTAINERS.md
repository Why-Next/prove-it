# Maintainers

`prove-it` is currently maintained by Why Next.

| Maintainer | GitHub | Scope |
| --- | --- | --- |
| Why Next | [@WhyNext](https://github.com/WhyNext) | Project direction, releases, security response |

## Maintainer Responsibilities

Maintainers are responsible for:

- keeping `main` protected and releasable
- requiring evidence for changes to hooks, workflows, and `SPEC.md`
- responding to security reports according to [SECURITY.md](SECURITY.md)
- cutting releases with checksums and provenance
- declining features that make the gate broader but less trustworthy

## Adding Maintainers

A new maintainer should have a track record of useful issues, reviews, or
patches, and should be trusted with the security boundary described in
[docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md). Additions happen by pull
request to this file and require approval from an existing maintainer.

## Removing Maintainers

A maintainer may step down by pull request. A maintainer can also be removed
when they are inactive for a long period or no longer have the trust needed for
release and security work. Removal should be explicit and recorded in this file.
